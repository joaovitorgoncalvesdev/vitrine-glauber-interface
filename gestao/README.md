# Gestão Vitrine Glauber

Aplicação administrativa independente da vitrine pública.

## Desenvolvimento

Na raiz do repositório:

```bash
npm run dev:gestao
```

A aplicação abre em `http://127.0.0.1:4175/gestao/login`.

Para executar este projeto isoladamente, instale suas dependências dentro desta pasta e use `npm run dev`.
